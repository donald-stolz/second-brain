# Weekly Review

## Steps

1. **Empty the Inbox**: Read 00 Inbox/CONTEXT.md. For each note listed, run the inbox-triage procedure (read the inbox-triage skill for detailed steps). Report how many notes were triaged and where they went.

2. **Review active projects**: Read 01 Projects/CONTEXT.md. For each note with status "active":
   - Read the note and check if the Outcome section is filled in
   - Check if Next Actions has at least one item
   - Flag any project missing an outcome or next actions

3. **Check areas**: Read 02 Areas/CONTEXT.md. For each area note:
   - Check the modified date — flag areas not updated in over 30 days
   - Check if Active Projects section has links — flag areas with no linked projects

4. **Archive stale items**: Scan 01 Projects for notes with status "done". Move them to 04 Archive, update their status to "archived", and update both CONTEXT.md files.

5. **Report summary**: List all changes made during the review:
   - Notes triaged from Inbox (count and destinations)
   - Projects flagged for missing outcomes or next actions
   - Areas flagged as neglected
   - Notes archived
   - Updated CONTEXT.md files

## When Not to Use

- Do not run a weekly review on a vault with no notes — there is nothing to review.

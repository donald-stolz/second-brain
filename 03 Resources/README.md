# 03 Resources

Topics of ongoing interest, kept for future reference — no obligation attached.

## Purpose

A Resource is anything worth keeping for its own sake: notes on a topic you're curious about, research, reference material pulled from articles or books. Nothing here needs to lead anywhere; it's a library, not a to-do list. If a resource becomes actionable, it graduates to `01 Projects`.

## What belongs here

- Reference notes on topics of interest
- Distilled notes from articles, books, courses, or clippings
- Anything you'd want to search for later, unattached to a specific project or responsibility

## Workflow

1. New resource notes typically start from the `Resource Note` template in `../Templates`, which captures source, key ideas, and personal thoughts separately.
2. Resources that stop being relevant move to `../04 Archive` rather than being deleted outright.

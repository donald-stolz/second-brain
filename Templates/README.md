# Templates

[Templater](https://silentvoid13.github.io/Templater/) templates used to create new notes with consistent frontmatter and structure across the vault.

## Purpose

Each PARA category has a matching template so new notes start with the right metadata (`type`, `status`, `created`, `tags`, etc.) and a predictable set of sections, instead of being built from scratch each time.

## Templates

- **Inbox Note** — quick, low-structure capture
- **Project Note** — outcome + next actions
- **Area Note** — description + active projects + connections
- **Resource Note** — source, key ideas, quotes/highlights, personal thoughts
- **MOC Note** — Map of Content, used to index and link related notes on a topic

These template files are generic and contain no personal data, so they're tracked directly in this repo (see the root `.gitignore` for the full whitelist of tracked paths).

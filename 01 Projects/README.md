# 01 Projects

Short-term efforts with a specific, defined outcome and a deadline or end point.

## Purpose

A Project is anything with a finish line: it's either done or it isn't. If something has been sitting around with no clear "done" state, it likely belongs in `02 Areas` (ongoing responsibility) or `03 Resources` (reference material) instead.

## What belongs here

- Work with a concrete deliverable or outcome
- Efforts with a target date, even a loose one
- Anything currently being actively worked on

## Workflow

1. New project notes typically start from the `Project Note` template in `../Templates`.
2. Each project note should capture its intended **Outcome** and a running list of **Next Actions**.
3. When a project is finished (or abandoned), move its note to `../04 Archive`.
